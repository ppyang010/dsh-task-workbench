# 0.4.1 默认工作区新会话验收

日期：2026-11-12。

## 选择规则

1. 优先使用看板当前筛选的有效工作区。
2. 筛选为全部或已失效时，沿用 DSH 当前选中会话所属工作区。
3. 两者均无效时进入原生工作区选择页。

依据实时工作区目录中的 ID 和会话归属，不按名称或硬编码路径猜测。目录未就绪时禁止导航。

## 原生接口

有目标工作区时调用 `uiWorkspace.openWorkspace(workspaceId)`，由原生服务准备或复用空白会话、切换主面板；不调用清除草稿功能，不发送消息或启动模型。无目标时调用 `clearMain()`。等待异步导航完成，期间禁止重复点击；失败在看板提示并允许重试。

- 类型检查、56 项测试、构建、包检查及 `git diff --check` 均通过。
- 新增 5 项测试：筛选优先级、全部/失效筛选回退、无当前会话与无有效工作区、目录未就绪、异步失败传播且不提前清空当前会话。
- 合成生产组件页面：正确传递筛选工作区 ID、全部工作区传递当前上下文语义、失败提示与重试通过。
- 实际 DSH GUI：筛选工作区后点击新建，原生「选择工作区」按钮显示预期工作区；回到看板选择全部工作区再新建，仍沿用相同原生当前工作区。两次导航前后输入内容相同，未录入或发送测试消息。
- 未在实机删除工作区制造失效场景；失效回退通过隔离测试验证。
