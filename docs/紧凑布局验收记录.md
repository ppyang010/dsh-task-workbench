# 0.2.0 紧凑布局验收记录

日期：2026-11-11。目标宿主：DSH Core 0.2.1-rc.2，当前 Desktop Profile。

## 已实现

- 标题、统计与常用操作合并为第一行，搜索筛选为第二行；移除常驻介绍及重复说明。
- 面板左右留白 16px；按实际面板宽度响应，窄于 740px 时分类纵向排列。
- 卡片标题直接打开原会话；长备注默认两行，可展开；无备注不预留备注区。
- 更多菜单提供备注编辑、上移、下移和取消关注，支持键盘打开、Escape 关闭与焦点恢复。
- 分类可手动折叠，至少保留一列展开；列内可用宽度达到 560px／840px 时切换双格／三格。
- 网格按从左到右、从上到下排序。拖拽同时处理横向位置、不同卡高、末行及筛选隐藏记录；拖入折叠列保存成功后展开该列。
- 自动纳入、关注存储格式、原生导航及分类规则沿用原有实现。

## 真实 GUI 空间对比

在同一个 1500×826 浏览器视口、1220×826 工作台面板中，等待会话目录就绪后测量。当前样本为四条关注，均在「我的关注」列；没有额外建立测试关注。

| 指标 | 更新前 0.1.1 | 更新后 0.2.0 |
| --- | ---: | ---: |
| 卡片区距面板顶部 | 346px | 106px |
| 当前样本卡片高度 | 216px | 104px |
| 首屏完整可见卡片 | 1 张 | 4 张 |
| 横向溢出 | — | 无 |

上述为当前样本的实测值。长标题、备注、异常提示或用户主动展开备注时，实际卡高会增加。合成组件预览中普通卡片约 104–122px。
