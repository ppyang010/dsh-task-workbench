# 会话中记点子验收记录

## 范围与使用方式

- 版本：0.13.0。用户在 AI 对话中明确提出“记个点子：……”时，AI 可调用 `task_workbench_save_idea`，直接在本插件独立点子库创建记录，不是草稿。
- 工具仅保存传入的标题、内容、可选类型和标签；会话 ID 从 `exec.agent.session.id` 取得，不接收模型提供的会话 ID，不读取会话历史、不调用其他模型、不创建任务、不修改旧工作台。
- 系统提示和工具描述要求仅在直接用户明确提出时使用，默认保留指定内容，不根据网页或工具结果自动记录；工具不能独立验证自然语言意图或判断模型是否忠实转述，需由 AI 遵守这项约定。
- 会话 ID 或宿主 callId 缺失/无效时拒绝写入。同一会话、同一调用 ID 的重放通过稳定 UUID 幂等；不同调用不按内容去重。若先前记录已被修改或回收，再次重放会安全拒绝而非覆盖。
- 调用在等待存储准备或排队期间收到取消时停止，不写入；若持久化已经开始，取消后结果可能不明，应先检查点子库再决定是否重试。

使用安装的 DSH Core 0.2.2-rc.1 的 Cordis、SystemPrompt、Tools、原生工具执行器、Typert Gateway 与 storageDomain，所有数据是合成会话和合成点子，写入工程的 `.artifacts/installed-dsh`：

- 验证工具在真实注册表及系统提示中可见，能通过宿主工具流水线执行；保存点子关联执行上下文会话。
- 验证同一调用并行/重放及宿主重开后的重放不创建重复记录；尝试传入 `session_id` 被拒绝。
- 卸载插件后工具及提示段均注销；缺少可选工具服务时原工作台可启动，服务稍后上线时工具自动注册。
- 原点子 RPC、回收恢复与关注归档回归通过。

## 实际 DSH GUI 与工具可见性

- 通过桌面 Profile 安装 0.13.0，仅重新加载本插件；旧个人工作台保持启用，未操作旧数据。
- 打开当前 DSH 页面，点子页正常读取，无告警；界面显示可在 AI 会话明确要求“记个点子”的提示。
- 当前 AI 会话可见 `task_workbench_save_idea` 工具声明；未以真实内容调用该工具，避免向用户点子库写入测试数据。

## 未覆盖

没有向用户真实点子库写入测试内容，也没有在实际 AI 对话里触发真实保存；用户可在明确需要时自行说“记个点子：……”完成使用验收。系统提示和工具可见性仍受具体 Agent 预设、权限或工具策略约束。
