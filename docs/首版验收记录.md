# 首版验收记录

版本：0.1.0。日期：2026-11-11。

## 已交付范围

独立插件「我的工作台」的首个模块「我的关注」。支持跨工作区关注已有会话、三列分类、列内排序、备注、筛选、多选添加、取消关注与撤销、自动纳入开关，以及原生会话导航。

分类由手动操作决定。自动纳入默认关闭；开启后只在普通会话开始新一轮时添加，取消关注加入排除名单。没有新增任务认领/执行/验收工具，也不向原会话发送消息。

## 使用真实 DSH 基础服务的隔离验证

安装版本：DSH Core **0.2.1-rc.2**。使用本机实际的 Cordis、Typert Gateway、storageDomain 和 JSON 后端；合成会话及存储只在工程 `.artifacts` 内。

验证插件依赖注入、owner RPC 调用、请求参数拒绝、原子落盘、关闭后重新挂载恢复、普通 fork 自动纳入、运行事件不改变已有分类。

真实 RPC 的 payload 必须为 `{ args: ... }`。初次实机检查发现客户端少了此信封，已修正，隔离集成脚本也改用 `invokeRpc`，增加缺少 `args` 必须被拒绝的断言。客户端控制器测试同步检查该信封，避免用直接方法调用掩盖传输错误。

## 生产组件的浏览器验证

使用生产 React 组件、控制器与数据层，目录及 RPC 采用本地合成会话。15 项交互断言通过，覆盖手动添加、换列、备注、导航目标 ID、取消与撤销、自动排除、断线保留、保存失败保留草稿及重试、真实拖拽、DSH 深色主题标记，以及 390px 窄屏无页面横向溢出。

此部分与真实 DSH GUI 验证分开记录。合成预览不会连接真实 DSH、读取真实会话或发送模型消息。

## 真实 GUI 验证

已通过官方 CLI 安装到当前 Desktop Profile。原有依赖版本全部保留，仅增加本插件；安装前已备份清单与锁文件。没有重启应用或停止现有会话。

在正在运行的 DSH GUI 中实际通过：

1. 侧栏出现「我的关注」，认证 RPC 返回成功，初始自动纳入为关闭。
2. 从真实会话目录按 ID 找到本次已有会话并关注。
3. 保存备注，并把运行中的会话换列后移回。
4. 刷新页面，关注、备注与分类仍保留。
5. 点击卡片打开同一原会话，关注面板关闭，原生输入区正常显示。

仅对本次会话建立一条关注并留下实机验证备注，方便体验；自动纳入保持关闭。未创建新会话或发送测试消息。

## 已知边界

- 「完成未读」沿用 DSH 页面内存状态，不表示任务验收通过，也不保证结果正确。
- 已归档或缺失会话保留卡片，但不会自动恢复或重建。
- 运行状态直接订阅；关注关系在面板显示时每 3 秒同步，重新打开时刷新。
- 首版固定三列；自定义分类、独立任务系统、日历和自动执行未包含。
- npm 尚未发布。GitHub 源码公开范围为源码、测试、文档与包配置，不含本机会话、个人 Profile、凭据、私有日志、`.planning` 或 `.artifacts`。
