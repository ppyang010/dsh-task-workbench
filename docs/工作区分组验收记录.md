# 0.3.0 工作区分组验收

日期：2026-11-12。

## 实现范围

每个分类列内按真实工作区 ID 分组，组头显示名称、数量、展开箭头；同名不同 ID 不合并。卡片移除重复工作区标签，保留原生导航、状态、备注与更多菜单。组顺序按名称稳定排序，组内保留人工顺序。折叠为面板内显示状态，不修改存储。

组内排序支持拖拽及上移、下移。跨分类移动只改变关注分类，不改变会话工作区；拖到其他工作区的区域时仍归入原工作区。搜索隐藏无匹配组并显示匹配数／总数；移动、添加、撤销成功后展开目标组。

## 自动化与合成页面

- 类型检查、47 项测试、构建、安装包检查、差异格式检查通过。
- 单元测试覆盖同名不同 ID 分组、目录缺失记录保留、组内人工顺序和锚点。
- 浏览器验证：折叠和展开、搜索计数、下拉跨分类归组、组内上移、真实指针跨工作区区域拖拽、移动后展开目标组、宽列三格布局、原导航入口、390px 无横向溢出。
- 32 张合成卡片场景验证：组内真实指针拖拽、列内滚动后的菜单可见、移动保存失败保留原分类、重试、取消关注后撤销恢复分组。
- 菜单检查最初误把“最后一张卡片”视为容器底部而等待向上展开超时；实际滚动后卡片居中，向下展开完全可见。按真实菜单和列的矩形边界复核通过，无需更改菜单实现。
