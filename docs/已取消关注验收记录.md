# 0.6.0 已取消关注列表验收

日期：2026-11-13。

## 已实现行为

- 顶部提供「已取消关注」入口和数量，列表支持标题、备注、会话 ID 搜索及工作区筛选，按取消时间倒序展示，分页渲染。
- 取消关注保留原记录、取消时间和同列后继锚点，包含已保存备注、人工分类、来源和创建时间。重复取消不覆盖快照。
- 列表恢复与撤销使用同一条原子恢复命令；保留原记录，版本递增，解除排除并移除取消快照。原锚点仍在同列则插回，否则放在原分类末尾。重复恢复不重复添加。
- 手动重新添加取消项时保留快照字段，采用明确选择的分类。
- 旧版仅排除 ID 的记录也出现在列表中，明确说明历史备注、分类和取消时间未保存；恢复至「我的关注」。
- 缺失、归档、子代理和其他不可用会话显示原因；断线和同步期间禁止恢复。会话不可用时保留取消记录。
- 原生会话只查询目录或通过既有入口打开；不恢复运行、不停止、归档或删除。数据仍使用独立存储域，不依赖旧个人工作台。

## 限制

旧版未保存的信息无法补回；新快照仅保存关注元数据，不复制原会话标题、工作区信息或正文，列表标题与工作区从当前原生目录读取。未实现永久清除、批量恢复或保留期限，这些不在本次授权范围。
