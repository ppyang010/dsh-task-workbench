# 0.5.0 自动待处理归集验收

日期：2026-11-12。

## 行为

- 我的关注中的等待回应、完成未读会话临时显示在等我处理，每条只出现一次。
- 临时展示不修改持久化分类、版本、备注或原顺序；处理后返回原列原顺序。
- 手动待处理常驻，暂时搁置不参与自动归集；未关注、断线、同步中和不可用记录不据缓存状态自动归集。
- 同一工作区内，手动待处理排在自动项前面；自动项保留原分类顺序，并标注原分类。
- 自动项可通过分类下拉或拖拽设为手动待处理或搁置；上下移动只对当前列的人工分类记录可用。
- 状态变化造成卡片跨列时，未保存备注仍保留。
