# 工作区分组整体移动验收记录

> 历史记录：0.14.0 对需求理解有误；0.15.0 已移除整组跨分类移动，改为同一分类内上下排序。本记录不代表当前版本功能。

## 范围

- 版本：0.14.0。支持拖动「我的关注」中的工作区组头，或点击组头「移动」，将当前分类中的该工作区分组移到其他分类。
- 移动前确认清单及筛选隐藏数量；移动只修改本插件的关注分类，不移动磁盘目录、不修改 DSH 原生工作区或会话。
- 后端按确认快照检查关注版本、工作区 ID 及成员，单次串行写入。目标分类已有成员不重排；新移动项按确认时组内顺序追加。
- 等待回应／完成未读的自动展示规则不变；原分类已属于目标时不作无谓改动。未确认工作区或分组内有未保存备注时禁用整组移动。

## 自动化与宿主基础服务

- `pnpm run typecheck`、`pnpm test`：通过，135 项测试、0 失败。
- `pnpm run build`、`pnpm run pack:check`、`git diff --check`：通过。
- 基于真实 DSH Core 0.2.2-rc.1 的 Cordis、WorkspaceRegistry、Typert Gateway 和 storageDomain，通过真实 RPC 使用合成工作区及会话验证整组移动；验证原生工作区成员保持不变。数据仅写入本工程 `.artifacts`。
- 覆盖无效工作区、跨工作区成员、版本冲突、保存失败及归档竞争；操作失败不会部分移动关注记录。

## 离线浏览器交互

使用生产组件、控制器与合成会话，不连接真实 DSH：

- 筛选仅显示 3 条时，确认框提示整组 24 条、其中 21 条隐藏；确认后 24 条均移至目标分类。
- 可直接拖动组头，也可点击「移动」；拖入折叠分类成功后自动展开。
- 模拟保存失败后原组 24 条仍在，重试成功；状态变化时确认按钮禁用并提示重新选择。
- 自动待处理项移回「我的关注」时保留自动展示语义；原有单卡拖拽仍可用。
- 430px 宽度下确认窗口可用、页面无横向溢出。

## 真实界面范围

安装 0.14.0 后仅重载本插件。在真实 DSH GUI 检查到工作区组头的「移动」入口可用，打开确认框确认包含“不移动电脑文件”的说明，随后取消；取消前后界面统计保持不变。
