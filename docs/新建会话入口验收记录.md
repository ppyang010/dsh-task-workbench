# 0.3.1 新建会话入口验收

日期：2026-11-12。

顶部新增「新建会话」，与「添加已有会话」并列。通过 `uiWorkspace.clearMain()` 进入原生空白会话页，用户在原生界面选择工作区并开始聊天。插件不自行创建 Agent 或发送消息，关注纳入仍沿用原有开关。断线、载入和保存期间禁用按钮，入口异常在看板显示错误。

- 类型检查、47 项既有测试、构建与安装包检查通过。
- 合成页面验证按钮回调、断线禁用、390px 窄屏无横向溢出。
- 本机正式安装 0.3.1，真实按钮进入显示「选择工作区」的原生空白页；关注记录的 ID、分类和备注在操作前后保持一致。
- 实机验证只进入新建页及打开工作区选择器，没有发送消息。
