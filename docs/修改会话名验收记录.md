# 0.4.0 修改会话名验收

日期：2026-11-12。

## 实现

卡片「更多操作 → 修改会话名」打开预填原名称的弹窗。保存调用宿主原生 `sessions.using(id, { source: 'workspaceOperation' }, ref => ref.binding.session.rename(title))`，与宿主侧边栏相同。宿主接受后更新标题投影，看板订阅原生目录；不单独存储名称。

去除首尾空白，禁止空名；不可用、归档、子代理、目录未就绪或离线时禁止改名。保存中拒绝重复提交，失败保留编辑输入，可重试。改名不导航、不发消息、不修改分类、备注或关注关系。
