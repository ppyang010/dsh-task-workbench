# 工作台设置入口验收记录

## 需求

- 版本：0.17.0。右上角增加带文字的「设置」按钮。
- 聊天背景、自动纳入开关、使用帮助移入设置界面。
- 「已取消关注」仍留在顶栏。顶栏日常操作保留：多选、已取消关注、设置、新建会话、添加已有会话。

## 自动化

- `pnpm run typecheck`、`pnpm test`、`pnpm run build`、`pnpm run pack:check`、`git diff --check` 通过；142 项测试、0 失败。
- 默认看板不渲染自动纳入开关、聊天背景按钮和帮助图标；设置按钮带 `aria-label="打开工作台设置"`。

## 合成页面

不连接真实 DSH：

- 顶栏按钮为多选、已取消关注、设置、新建会话、添加已有会话。
- 设置弹窗含自动纳入开关、聊天背景表单和使用帮助；不含已取消关注。
- 开关可即时保存，提示出现后弹窗仍打开；再次打开仍为已开启。

## 真实界面

安装 0.17.0 后仅重载本插件。打开「我的任务工作台」只读核对：顶栏为多选、已取消关注、设置、新建会话、添加已有会话；无聊天背景按钮、自动纳入开关和帮助图标。点击「设置」后弹窗含自动纳入、聊天背景和使用帮助。点「完成」关闭，未改关注分类。
