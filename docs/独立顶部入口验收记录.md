# 0.3.4 独立顶部入口验收

日期：2026-11-12。

本插件独立注册宿主 `conversation.session.header.actions`，使用 `id: personal-workbench` 和 `priority: -10`。同位置旧入口默认优先级为 0，由宿主决定仅渲染本插件入口。按钮只调用 `layout.selectPanel(PANEL_ID)`，不调用旧工作台服务或修改其数据。旧插件的侧边栏入口保持原样。

## 宿主槽位生命周期验证

通过当前已安装宿主的真实 `SlotCore` 执行隔离验证，并使用生产代码 `registerHeaderEntry`：

- 旧插件先注册和本插件先注册，两种顺序均只呈现本插件入口。
- 移除旧插件注册后，本插件入口仍存在，导航目标正确。
- 重新注册旧插件后仍只呈现本插件入口。
- 移除本插件注册后，旧插件入口自动恢复。

这是实际宿主注册表的隔离生命周期验证，没有实际卸载用户的旧工作台。

## 实机验证

安装 0.3.4 后刷新现有 GUI，打开已有会话：顶部只显示一个「工作台」按钮，点击进入「我的关注 / 等我处理 / 暂时搁置」。从卡片再次打开原会话，页面 URL 与现有输入内容保持一致。未发送消息、创建会话或改变关注关系。

安装前后旧插件的清单、客户端与宿主入口文件 SHA-256 一致，其他插件依赖声明与 bundles 一致；本插件安装产物与当前构建逐字节一致。
