# 会话卡片整卡呼吸验收记录

## 需求

- 版本：0.16.0。运行中、等待回应、完成未读的关注卡片改为整卡呼吸，不再只闪状态标签。
- 空闲卡片、顶部统计、拖动中和多选中的卡片保持静态。系统「减少动态效果」仍关闭全部动画。

## 自动化

- `pnpm run typecheck`、`pnpm test`、`pnpm run build`、`pnpm run pack:check`、`git diff --check` 通过。
- 卡片测试确认活动状态写入 `data-dtw-status`，空闲卡片不参与呼吸选择器。

## 合成页面

不连接真实 DSH：

- 运行中卡片使用 `dtw-card-breathe`，时长 2.8s。
- 等待回应 2.2s，完成未读 3.4s。
- 状态标签本身不再整段呼吸，仅状态点继续轻微缩放。
- 空闲卡片 `animation: none`。

## 真实界面

安装 0.16.0 后仅重载本插件。打开「我的任务工作台」只读核对：目录就绪后 2 张运行中卡片使用 `dtw-card-breathe`（2.8s），17 张空闲卡片 `animation: none`，无错误横幅。未改分类或分组顺序。
