# 我的任务工作台 · dsh-task-workbench

面向 DeepSeek Harness 的独立个人工作台插件，包含 **我的关注** 与 **点子** 两个模块：整理需要跟进的原生会话，也可以独立记录想法并关联已有会话。

包名：`@ppyang010/dsh-task-workbench`。此插件与社区的 `dsh-taskboard`、`dsh-personal-workbench` 是不同项目，可独立使用。

## 首版功能

- **会话顶部入口**：顶部「工作台」位于子智能体入口之后，点击打开本插件。使用宿主 `conversation.session.header.actions` 槽位，以 `personal-workbench` 入口 ID、`priority: -10` 独立注册。旧个人工作台同时安装时只接管其顶部按钮，侧边栏与数据保持原状；旧插件卸载后本入口继续存在。本插件卸载则由宿主恢复仍在安装的旧入口，不修改其他插件文件。
- **新建会话入口**：顶部「新建会话」优先采用看板筛选的有效工作区，否则沿用 DSH 当前会话的工作区；没有有效工作区则显示原生选择页。通过原生入口准备或复用空白会话，保留已有草稿，不发送消息或启动模型；不自动添加关注，仍遵循自动纳入开关。
- **已有会话手动加入**：读取 DSH 原生会话目录，支持跨工作区搜索、多选和去重；无需重新发送消息或启动模型。
- **我的关注／等我处理／暂时搁置**：拖拽换列、列内排序，并提供分类下拉作为等效操作。
- **修改会话名**：卡片「更多操作 → 修改会话名」预填原名，保存后同步更新 DSH 原生会话列表与标题；取消不保存，失败保留输入可重试。断线、归档或不可用会话禁止改名。
- **卡片备注**：备注属于关注记录，版本冲突时保留正在编辑的内容，避免覆盖其他窗口的修改。
- **原生运行状态**：订阅 DSH 的运行、等待审批/方案确认/回答、完成未读状态。这些活动会话默认同步出现在中间列，原卡片不离开「我的关注」；可在设置中关闭同步。暂时搁置不参与同步。
- **打开原对话**：调用 DSH 原生 `uiWorkspace.openSession`；历史、附件、模型和技能仍在原生会话页使用，其他原有输入入口继续可用。
- **已取消关注**：顶部入口显示已移出的记录，支持搜索标题、备注、会话 ID 及工作区筛选；可查看取消时间、原分类和备注，打开原对话或恢复关注。取消关注不停止运行，不移动、归档或删除会话。
- **归档即自动取消关注**：明确归档的会话自动移入已取消关注，现有归档关注同样处理。宿主启动、读取、修改及每2秒核对归档集合，关闭面板仍执行；展示随看板同步刷新。保留原分类、已保存备注及排序锚点，不修改原生会话。恢复归档不会自动关注，需手动恢复；目录缺失或断线不等于归档，存储失败保留原记录并重试。
- **恢复关注**：新取消记录保留分类、已保存备注、创建时间和排序锚点；原锚点仍在同列则恢复原相对位置，否则放到原分类末尾。恢复与撤销为同一原子操作，避免部分恢复；已取消的会话不会自动纳入，手动恢复后解除排除。
- **历史取消记录**：旧版本仅保存排除 ID，升级后可查看并恢复到「我的关注」，无法补回未保存的备注、时间和原分类；列表明确说明。缺失、归档或不可用会话保留记录且禁止恢复，等待目录重新可用。不提供永久清除、批量操作或自动过期。
- **宿主持久化**：关注关系、顺序、备注、设置和排除名单通过独立 `storageDomain` 保存，不依赖页面 localStorage。

## 哨兵

工作台顶部「哨兵」读取已启用的 `dsh-sentinel` 插件。可以按关联会话的活跃状态筛选值守记录，展开查看监控对象、触发条件和最近结果，也可打开关联会话或原生「哨兵监控」。页面展示哨兵服务提供的近期触发记录，仅在页签打开时刷新。

## 点子

通过工作台顶部「我的关注 / 点子」切换模块，切换不会清空已打开的关注筛选或点子编辑状态。首版提供：

- **记录和编辑**：标题、正文、类型、标签；正文可保存 Markdown 原文，目前按文本展示，不执行 HTML。支持搜索标题、正文和标签，以及按类型筛选。
- **文件夹**：新建、编辑名称与摘要、删除、合并；一个点子最多属于 50 个文件夹。删除或合并文件夹只调整归类，不删除点子，也涵盖回收站内的点子。
- **回收站**：移入回收站后可恢复，保留正文、标签、现存文件夹及关联会话。首版不提供永久清除或自动过期。
- **关联已有会话**：只保存用户选择的会话 ID；从点子详情可打开原生会话。不可用或归档的关联保留但禁止打开；不读取聊天正文、不发送消息。
- **复制讨论材料**：只在用户点击时复制点子标题、类型、标签和正文，供自行粘贴；不自动创建会话、发送消息或启动模型。
- **会话里随手记**：在支持本插件工具的 AI 会话明确说「记个点子：……」，AI 可调用 `task_workbench_save_idea` 直接保存，不是待确认草稿。工具仅接收用户指定的正文，默认保留原文；工具自动关联执行上下文的当前会话，不能由模型指定别的会话 ID。

点子与文件夹保存在独立 `ppyang010_task_workbench_ideas` 存储域，和已有关注域、旧个人工作台均隔离。空库首次启用；**不读取、修改或自动导入旧点子数据**。旧数据导入如有需要另行确认。每条点子最多 20 个标签、20 个关联会话，正文最多 40000 字；单库最多 10000 条点子和 1000 个文件夹。列表目前加载本库并分批渲染，超大规模下的性能未做专项测试。

写入串行落盘，跨窗口编辑采用版本校验；冲突时保留草稿，显示最新内容，由用户选择是否按最新版本继续保存。会话工具只应在用户明确要求保存时使用，不会自己读取聊天历史，也不根据网页或工具输出的指令自动记点子；用户意图与原文选择仍依赖 AI 正确理解。仅相同会话与同一次工具调用的重放保证幂等，不同调用即使内容相同也会新建；结果不明时应先到点子列表确认再重试。AI 自动分组、点子转任务树和一键导入旧数据均不在当前版本。

## 独立聊天背景

工作台右上角「设置」中的「聊天背景」提供开关、色值输入和颜色选择器。默认关闭，预置米白色 `#F3F0E7`，启用并保存后仅覆盖浅色原生聊天内容区背景（含输入框周围空白），深色模式沿用原样。不改变输入框本身、字体、强调色、侧栏、顶部标题栏或设置窗口，不复制整套主题。

设置保存到本插件独立存储，刷新/重启后读取；不需要 Dream Skin 或其他主题插件。恢复 DSH 默认即关闭本插件覆盖；如果其他主题插件仍启用，其样式仍会生效。旧主题迁移应先记录原配置，停用后核验，再决定卸载，不自动删除其数据。

使用宿主 `data-conversation-content` / `data-conversation-region="chat"` 标记限定范围，不依赖构建哈希类名、不写全局主题 token。宿主标记不兼容时不着色，不退化为全局覆盖。用户色值严格校验为六位十六进制；建议使用浅色以保持原生文字可读。

## 紧凑布局

- 标题统计和搜索筛选集中在两行，按面板实际宽度自适应，正文区左右保留 16px。
- 顶部运行中、等待回应、完成未读、空闲统计可点击筛选，再次点击取消；已关注按钮清除状态条件。选中高亮且与状态下拉框同步，保留搜索和工作区条件。统计数字始终基于全部已关注会话；改变状态条件会清空多选。
- 桌面三列填满剩余高度，底部保留 16px；长列表按列独立滚动，顶部和列标题保持可见，卡片不拉伸。窄面板可滚动访问纵向分类。
- 点击卡片「打开对话」按钮或标题打开原会话；标题最多两行，悬停查看完整名称。备注默认一行，可展开完整内容；没有备注时不保留空白备注区。
- 「取消关注」位于卡片更多菜单，可撤销、不删除会话。「更多操作」还提供移动到分类、查看来源、修改会话名、备注编辑、上移和下移；分类与自动纳入来源不常驻占位。状态位于标题右侧的卡片右上角，会话更新时间位于左下角，与打开按钮同一行；悬停说明该时间来自 DSH 目录 updatedAt，不等同于上次 AI 回复时间，保留空闲标签和完整自动待处理说明。运行中、等待回应、完成未读的整张卡片会随状态轻轻呼吸，空闲卡片保持静态。
- 卡片收紧内边距并取消最小高度，不缩小字号；拖拽手柄在悬停、键盘焦点、拖动时显示，触屏环境保持可见，拖拽分类和排序逻辑不变。
- 分类标题旁的箭头可折叠该列，至少保留一个展开分类。折叠是当前面板的显示状态，不修改关注数据。向折叠列拖入卡片后，会在保存成功后展开目标列。
- 每列按工作区 ID 分组，默认按工作区名称排序；组头显示名称和数量，可独立折叠，折叠仅在当前面板生效。同名不同 ID 不合并，目录缺失记录归入「工作区待确认」。搜索只显示有匹配卡片的组，计数显示匹配数／组内总数。
- 同一工作区内保留人工顺序，上移、下移和卡片拖拽排序只作用于同组。跨分类移动后归入原工作区分组，拖入其他工作区区域也不会改变会话所属工作区。移动、添加和撤销成功后展开对应组。
- **工作区分组上下排序**：在同一分类内拖动工作区组头，或点击组头旁的上、下箭头。每列顺序独立保存，刷新和重启后保留；暂时消失的分组重新出现时沿用原有位置，新分组排在已排序分组之后并按名称排列。筛选时排序也包含被隐藏的分组。
- 分组排序只写本插件的独立顺序设置，**不会改变任何会话分类、组内卡片顺序或电脑文件**。组头不能跨分类拖动；卡片原有的跨分类移动功能不变。工作区尚未确认、排序数据未加载或有备注草稿时暂不可排序；数据冲突时刷新后重试。
- 列内可用宽度达到 560px／840px 时，同组分别显示两格／三格卡片，顺序从左到右、从上到下。面板窄于 740px 时改为单列排列分类。
- 右上角「设置」集中自动纳入开关、中间列同步展示、聊天背景和使用帮助；顶栏保留多选、已取消关注、新建会话和添加已有会话。

## 中间列同步展示

中间列分成上下两块，标题层级与「我的关注」「暂时搁置」相同：上块「运行中」，下块「等我处理」。默认开启同步：我的关注里运行中、等待回应、完成未读会同时出现在中间列，**原卡片不离开「我的关注」**。关闭后，中间列只保留手动放入「等我处理」的会话。暂时搁置不参与同步。

同步卡片用于查看，不提供拖拽改分类；分类、组内排序仍以「我的关注」原卡片为准。下块分组顺序仍按「等我处理」列保存。断线、目录同步中或原会话不可用时不同步。

## 多选批量取消关注

点击顶部「多选」，勾选卡片或「全选筛选结果」，再点「取消关注所选」。确认窗口列出本次目标，确认后一次保存；失败不部分取消，保留选择可重试。最多500条，全选包含折叠的分类和分组；更改筛选会清空选择，运行状态变化导致已选项隐藏时显示隐藏数量。取消后可从「已取消关注」逐条恢复。

多选期间禁用拖拽、打开对话及单卡修改，退出多选恢复；正在编辑备注时需先保存或取消草稿。单条取消仍在更多菜单。批量取消关注不删除、归档或停止原会话，不提供批量移动或一键恢复整批。归档是另一项需单独确认的操作，见下节。

## 在工作台归档会话

- 单条：卡片「更多操作 → 归档会话」。批量：顶部「多选」后勾选，点击「归档所选」。确认窗口列出本次目标，取消不执行。
- 调用与 DSH 原生侧栏相同的 `workspaces.archiveSession(id, { stopActivity: false })`，不创建另一套归档标记；本次操作若触发原生 clearArchivedCurrent 清空主面板，则保留工作台以展示结果，不恢复已归档会话引用；用户主动导航时不抢回页面。
- 运行中的任务或活动由 DSH 原生接口拒绝，不强制停止。批量最多500条，逐条执行，允许部分成功；结果逐条展示，重试只针对失败项。连接中断后不继续发送后续请求，可能已到达宿主但未收到结果的失败项应先刷新确认。
- 归档成功后按现有规则自动取消关注；关注同步失败与原生归档结果分开提示，稍后刷新重试同步，不自动撤销已经成功的归档。
- 恢复归档请通过 DSH 原生入口，然后按需在「已取消关注」手动恢复关注。归档不是删除，不提供强制停止并归档或批量回滚。

## 复制名称和 ID

工作台卡片右下角三个点菜单也可 **复制 Session ID** 或 **复制名称和 ID**，格式相同。

在 DSH 左侧会话列表右键菜单中，「复制 Session ID」下方新增独立菜单项 **复制名称和 ID**。无需开关或先关注会话，也不依赖旧个人工作台插件。

原来的「复制 Session ID」仍只复制 ID。点击新增菜单项会复制右键目标的名称与 ID：

```text
会话名称
session-id
```

名称为空时仅复制 ID 并提示；复制失败不会提示成功。通过宿主 `contextMenus` 注册独立动作，不拦截原生点击、不覆盖图标、不修改原生文件或全局剪贴板函数。卸载时移除该菜单项。0.7.0 的历史开关字段保留兼容读取，但不再影响复制行为。不支持菜单扩展的旧宿主保留原生复制和工作台功能。

## 自动纳入开关

默认关闭，入口在右上角「设置」。开启后，普通会话开始新一轮时自动加入「我的关注」，旧会话续聊也适用。

| 情况 | 行为 |
| --- | --- |
| 开关关闭 | 只手动添加，已有卡片保留 |
| 开关开启，新会话或旧会话开始新一轮 | 未关注且未排除时新增卡片 |
| 已关注的会话继续运行 | 只更新运行状态，不重复添加、不改分类 |
| 仅打开历史会话查看 | 不纳入 |
| 子代理会话 | 不自动收录 |
| 手动取消关注 | 记录排除，之后自动纳入会跳过；手动重新添加可解除 |
| 运行结束、异常或等待交互 | 分类不变，状态展示跟随 DSH |

不一次性回扫全部历史。已有归档会话、目录尚未就绪或不可兼容格式的会话会显示原因，不会为了打开卡片自动恢复或重建会话。

「完成未读」沿用 DSH 页面内存中的提醒语义：它表示后台一轮结束后尚未查看，并不保证结果正确或任务已完成；刷新页面后是否保留由 DSH 原生状态决定。

## 安装与兼容

首版针对 **DSH Core `0.2.1-rc.2`、Node.js 22.15+**。桌面应用的外壳版本与 Core 版本不是一回事。首版安装包需要包含构建后的 `lib`，不要直接把未构建源码目录当作成品安装。

拿到本项目打包的 `.tgz` 后，在目标 Profile 安装：

```bash
dsh plugin --profile desktop add /绝对路径/ppyang010-dsh-task-workbench-0.18.5.tgz
# Web 用户改为 --profile web
```

是否立即加载取决于宿主的插件重载能力。如入口尚未出现，等现有工作结束后完整退出并重新打开 DSH；不要为了安装中断正在运行的会话。

入口为左侧 **我的任务工作台**，进入后可使用「我的关注」和「点子」模块。卸载时仅移除插件，不主动清除已保存的关注和点子数据：

```bash
dsh plugin --profile desktop remove @ppyang010/dsh-task-workbench
```

## 数据与边界

- 独立存储域：关注与设置使用 `ppyang010_task_workbench`，点子使用 `ppyang010_task_workbench_ideas`。实际文件路径由 DSH 当前存储后端配置决定。
- 保存关注会话 ID、分类、备注、顺序、设置，以及用户手动录入或明确要求 AI 保存的点子内容和关联会话 ID；不自动复制聊天正文，不保存凭据，不向外部服务发送数据。
- 客户端使用宿主的认证 RPC；提供一个供 AI 会话显式保存点子的原生工具，无新增网络监听端口或遥测。
- 不注入任务认领、执行、验收等 Agent 指令。
- 运行状态即时订阅宿主；面板显示时每 3 秒同步轻量关注关系，以反映自动纳入和其他窗口操作。后台面板不轮询，重新打开时刷新。
- 多窗口操作由宿主串行处理；备注编辑另外校验卡片版本。
